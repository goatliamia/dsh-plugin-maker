# UX 原则库（感受 → 规则）

> 每条来自真实使用中的"难受"。当前向导为文本呈现、无 UI 输出——本文件供图形界面路线图实现时读（暂无消费者）。

## U1 引用是"指向"，不是"搬运"
来源: 划选标注把整段原文塞进输入框，像抄了一大批文档，太重。
规则: 引用默认只带短标识（消息锚点 + 一句话摘要）；全文只在悬停/展开时可见。

## U2 标注顺序是用户的，不是原文的
来源: 多条注释被强制按原文顺序组织，违背用户心智。
规则: 标注列表自由排序/分组；原文顺序只作默认值。

## U3 一个选区 = 一次点击
来源: 划选后要点出对话框之外才能完成注释，操作链太长。
规则: 划选 → 浮层 → 点击即完成。任何需要"点击别处才能继续"的流程都是 bug。

## U4 回复轻量化
来源: 长回复被引用后变成"一大批文档"，阅读负担重。
规则: 助手回复默认精简，长内容进文件，聊天里只留路径。
